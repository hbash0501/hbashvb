# بنية بصيرة 26.10

واجهة البداية: BasiraShellForm. البيانات والخدمات السابقة محفوظة في AppServices. أزيلت ArchiveWorkCenterForm لأنها استبدلت بالشاشة الجديدة. ملفات التصميم والمنطق منفصلة للنوافذ الجديدة.

| المكوّن | المسؤولية |
|---|---|
| BasiraEngine | فهرس ذاكرة بمفردات عربية، BM25، أدلة موضعية، مواعيد وتنبيهات وروابط بالقواعد |
| BasiraAssistantService | أدلة محلية أولاً؛ صياغة اختيارية مع استبعاد المصادر الحساسة في هذا المسار |
| BasiraCitations | فحص وجود الإحالات وصحة أرقام المصادر |
| BasiraStore | مجموعات ونسخ نص/بيانات، حفظ ذري مع نسخة احتياطية |
| BasiraCaseExportService | حزم أدلة ZIP، Word وXML وبصمات للملفات المصدرة |
| BasiraDocumentEditorForm | تحرير بيانات ونص، منع الحفظ عند معالجة نشطة أو تغير نسخة السجل |
| BasiraRevisionViewerForm | قراءة النسخ ومقارنة الأسطر الفريدة |
| ProcessingJobQueueService | FIFO لكل مستند، عمال متوازيون لمستندات مختلفة، إلغاء وتاريخ محفوظ |
| CancellableProcess | قراءة stdout/stderr بالتوازي وإيقاف عملية OCR/PDF عند الإلغاء أو المهلة |
| PasswordHashService | PBKDF2-SHA256، مع قبول تجزئات الدخول السابقة وترقيتها عند نجاح الدخول |
| ArchiveRepository | XML الأساسي، ومراجعة إصدار للواجهة، وحفظ نسخة المستند السابقة قبل التعديل |
| EnterpriseSqliteService | قاعدة مساعدة من المشروع السابق؛ تضمين DLL الصحيح ومكتبات x86/x64 |

يجري تحميل الأرشيف وبناء الفهرس والبحث والأسئلة والحزم في الخلفية. سجل النسخ يُقرأ خارج خيط الرسم. تحديث المؤشرات يرتبط بتغير إصدار المستودع. الدوال الثقيلة القديمة الأخرى تحتفظ بحدودها الحالية؛ يلزم قياس واقعي على ملفات المستخدم قبل نشر مؤسسي.

في 26.10.3 أضيف BasiraJobNotifications لتحديد نهايات المهام ومنع التكرار. أحداث الطابور وقائمة المهام تُعاد كنسخ مستقلة عن كائنات العمال. شريط الإدراج وإشعار المعالجة جزء من BasiraShellForm.Designer، ومنطق WIA في خدمة مستقلة يعمل عبر عامل STA.
